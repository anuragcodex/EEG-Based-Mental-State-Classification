# EEG-Based Mental State Classification

## Overview
This project investigates machine learning approaches for classifying mental states from EEG-derived features. It includes data preprocessing, feature engineering, subject-independent validation, and comparison of multiple classification models.

## Dataset
- EEG dataset
- Target: Mental state classification
- Features: EEG-derived measurements

## Workflow
- Data preprocessing
- Feature engineering
- Subject-independent validation (GroupKFold)
- Model training
- Model evaluation

## Models
- Support Vector Machine (SVM)
- Logistic Regression
- Random Forest

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

## Technologies
Python, Pandas, NumPy, Scikit-learn, Matplotlib
